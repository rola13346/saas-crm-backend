# Multi-Tenant CRM SaaS

## Overview

A multi-tenant CRM SaaS platform built with Laravel, designed to help companies manage their customers, users, and business operations.

Each company will have its own isolated database to ensure data privacy and security.

## Technology Stack

- PHP
- Laravel
- Docker
- Nginx
- PostgreSQL
- Git

## Installation

### Prerequisites

- Docker
- Docker Compose
- Git

### Setup

1. Clone the repository.
2. Navigate to the project directory.
3. Copy `.env.example` to `.env` and configure the environment variables.
4. Build and start the application:

   ```bash
   docker compose up -d --build
   ```

## Planned Features

- Multi-tenant architecture
- Company and user management
- Authentication and authorization
